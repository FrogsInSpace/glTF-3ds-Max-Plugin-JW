# glTF 2.0 Importer/Exporter for Autodesk 3ds Max

This document describes an importer plug-in for importing glTF format
files into Autodesk 3ds Max scenes and an exporter plug-in that exports
scene data to glTF format files.

Documentation for end users is divided into sections:

- **[glTF Importer](ImporterDocumentation)** explains the options for importing and formatting the scene for use in 3ds Max.
- **[glTF Editing](EditingDocumentation)** explains the tools within 3ds Max for editing and preparing glTF content.
- **[glTF Exporter](ExporterDocumentation)** explains the options for exporting the scene out from 3ds Max into glTF format.
